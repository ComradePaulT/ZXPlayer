ZXPlayer publisher logos

Place publisher logo images in this folder. Name each image after the publisher
shown on the folder screen. Examples:

  Ocean.png
  U.S. Gold.png
  Firebird.png
  Gremlin Graphics.png
  Codemasters.jpg
  Hewson.png

ZXPlayer accepts PNG, JPG, JPEG, WEBP, BMP and GIF. Transparent PNG images give
the cleanest result. It ignores capitalisation and punctuation. It also tries
the name without common endings such as Software, Systems, Games, Consultants,
Group, Computing and Ltd, so Firebird.png matches Firebird Software and
Gremlin Graphics.png matches Gremlin Graphics Software.

The folder name remains visible when no matching logo has been added. Scan the
library again with Refresh after copying new logo files.

AUTOMATIC DOWNLOAD

On the Publisher folder screen, tap Get logos. ZXPlayer checks publishers in
your tape filenames against the World of Spectrum Publishers API and downloads
available logos into this folder. It skips existing images. A large collection
can take a few minutes; Cancel safely stops it and you can run it again later.
